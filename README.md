# 智能玩具轮换

智能玩具轮换会为每个方案创建一个独立按钮。每次点击方案按钮时，插件会按该方案内的分组顺序寻找一个可执行分组，并随机使用该分组中的一个可用玩具。

## 安装

把 `SmartToyRoller` 文件夹放到：

```text
World of Warcraft/_retail_/Interface/AddOns/
```

然后重启游戏或执行：

```text
/reload
```

## 使用

输入：

```text
/stro
```

在配置窗口里新建方案、创建分组、搜索玩具并加入分组。新方案的自定义按钮默认隐藏，动作条宏仍可直接使用。保存方案后，配置窗口会显示该方案对应的动作条宏，例如：

```text
/click SmartToyRollerButton_fishing LeftButton
```

把对应宏拖到动作条即可执行该方案。每个方案都有自己的按钮和宏，互不影响。

## 配置

- 方案：一个独立执行入口，会生成自己的按钮和宏。
- 策略：`顺序` 会从第一个分组开始找可用玩具；`轮转` 会从上次执行后的分组继续找。
- 分组：方案内的轮换池；分组横向排列，点击分组按钮可编辑名称和跳过效果 ID。
- 本组跳过效果 ID：如果玩家身上已有任意一个效果，本次会跳过该分组。
- 玩具选择：支持按玩具名称或 ID 搜索。点击玩具后选择加入已有分组，或新建分组并加入。
- 本组玩具：滚动展示当前分组的玩具，右键已加入的玩具可以从当前分组移除。

可重复使用的巨型鱼漂加入分组时，会自动填入已知的跳过效果 ID `207700`。
